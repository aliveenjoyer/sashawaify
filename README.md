# Заявка в модеры sashawaify

Страница-анкета для тех, кто хочет стать модератором канала [sashawaify](https://www.twitch.tv/sashawaify) на Twitch:
https://sashawaify.aliveenjoyer.art

Обычная статичная страница без сборки: `index.html`, `css/page.css`, `js/app.js`. Вопросы лежат в `js/questions.js`,
там же видно, какой вопрос откуда взялся. Заполненная анкета уходит на сервер и оттуда в Telegram.

Черновик ответов хранится в браузере посетителя (`localStorage`), пока анкета не отправлена.
